## Overview

This is a study project focused on understanding braindecode — an open-source Python library
for decoding EEG signals using deep learning. I am not the author of this library.

> **Attribution:** [braindecode](https://github.com/braindecode/braindecode) is developed by Robin Tibor Schirrmeister et al.
> This project documents my study of it, not original work.

## Problem / Motivation

I became interested in EEG signal processing while exploring AI/ML applications in neuroscience.
Braindecode is the most comprehensive open-source toolkit in this space, making it an ideal
starting point for understanding the domain.

## What I Learned from the Original

- How EEG data is structured (channels × time points)
- How MNE-Python handles raw EEG preprocessing
- ShallowConvNet and DeepConvNet architectures for EEG classification
- The WindowsDataset pattern for temporal signal segmentation
