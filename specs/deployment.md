# deployment.md — Deployment Specification

**Spec ID:** SPEC-DEPLOY-001  
**Version:** 1.0

---

## 1. Purpose
Define the complete CI/CD pipeline from git push to live GitHub Pages.

## 2. Pipeline
```
git push → main
    ↓
GitHub Actions triggers
    ↓
Checkout repository
    ↓
Setup Node.js ≥22
    ↓
npm ci (clean install)
    ↓
npm run build (astro build + pagefind)
    ↓
Upload artifact (dist/)
    ↓
Deploy to GitHub Pages
    ↓
Site live at https://USERNAME.github.io/REPO/
```

## 3. GitHub Pages Configuration
- Source: GitHub Actions (not branch)
- Permissions: GITHUB_TOKEN with pages write + id-token write

## 4. SEO Files
- robots.txt: Allow all crawlers
- sitemap.xml: Auto-generated by @astrojs/sitemap

## 5. Acceptance Criteria
- AC-D-001: Push to main triggers deployment automatically
- AC-D-002: Build succeeds without manual intervention
- AC-D-003: Site accessible at GitHub Pages URL after deployment
- AC-D-004: Sitemap.xml accessible
- AC-D-005: Robots.txt accessible

## 6. Configuration Required (one-time)
- Go to repo Settings → Pages → Source → GitHub Actions
- Go to repo Settings → Actions → General → Workflow permissions → Read and write permissions
